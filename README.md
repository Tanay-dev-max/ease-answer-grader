# EASE: Explainable Answer Scoring Engine

EASE grades a student's descriptive answer against a reference answer and explains every grade.
It extracts five NLP signals, fuses them with a learned model trained on 2,273 human-graded
answers, and shows how many points each signal added or removed.

**Team:** Venkatapuram Tanay (23MIS0202) · Vishal CS (23MIS0315) · Harish Kumar E (23MIS0368)

## How it works

| Step | Signal | Tool |
|---|---|---|
| 1 | Semantic similarity between student and reference answer | Sentence-BERT (all-MiniLM-L6-v2) |
| 2 | Concept coverage: share of the reference's noun phrases the student used | spaCy (en_core_web_sm) |
| 3 | Entailment probability: does the student's answer support the reference? | BART-large-MNLI |
| 4 | Contradiction probability | BART-large-MNLI |
| 5 | Keyword overlap, with words copied from the question removed ("question demoting") | our code |

**Fusion.** A gradient-boosted tree model (scikit-learn `HistGradientBoostingRegressor`) learns how
to combine the five signals from human grades. Monotonic constraints guarantee that more similarity,
coverage, entailment or overlap can never lower the score, and more contradiction can never raise it.

**Explanation.** For every answer, EASE computes exact Shapley values (the method behind SHAP) over
the five signals, so the dashboard shows how many points each signal added or removed relative to
the average answer. It also lists matched and missing concepts, highlights the words that matter
most (occlusion), and writes short feedback. Answers with contradiction probability above 0.9 are
flagged for teacher review.

## Results (Mohler dataset, 2,273 answers, 81 questions)

5-fold cross-validation. "Unseen questions" means the test questions never appear in training.

| System | Pearson (random) | Pearson (unseen questions) | MAE (unseen, 0-5) | RMSE (unseen, 0-5) |
|---|---|---|---|---|
| Similarity only (baseline) | 0.494 | 0.491 | 0.726 | 0.955 |
| Linear fusion (Ridge, 5 signals) | 0.606 | 0.606 | 0.646 | 0.878 |
| **EASE (monotonic boosted trees)** | **0.666** | **0.652** | **0.594** | **0.832** |

- EASE improves Pearson over similarity alone by +0.173 (bootstrap 95% CI +0.148 to +0.198).
- Typical error: ±1.2 points out of 10 on unseen questions.
- For reference, published Mohler results include r = 0.592 / RMSE 0.887 (Sultan et al., 2016,
  feature-based) and r = 0.480 (Mohler et al., 2011, bag of words). These used different splits,
  so the comparison is indicative, not exact. Fine-tuned transformers report higher correlations.

Full tables (ablation, signal importance, grade bands, contradiction check) are in `results.md`,
regenerated by `python train.py`.

## Honest findings and limitations

- **Scores are compressed toward the average.** Only 7.5% of Mohler answers are graded 4/10 or lower,
  so wrong answers are rare in training. EASE ranks answers in the right order in every grade band,
  but an on-topic wrong answer can still score around 6-8/10.
- **Contradiction is a flag, not a penalty.** Of answers with contradiction probability above 0.9,
  59% were graded 4/5 or higher by humans, so a hard score cap would punish many correct answers.
- **Concept coverage explains, but barely scores.** Removing it changes Pearson by 0.001. It is kept
  for the matched/missing concept feedback, not for accuracy. Matching is lexical, so spelling
  variants (behaviour/behavior) and synonyms are missed.
- EASE is a teacher's assistant, not a replacement for a human grader.

## Run it

```
pip install -r requirements.txt
python -m spacy download en_core_web_sm
python get_data.py              # download the Mohler dataset (only needed once)
python build_features.py 3000   # extract the NLP signals (about 15 min on CPU, only needed once)
python train.py                 # train, evaluate, write results.md and ease_model.joblib
streamlit run app.py            # dashboard
```

## Files

| File | Purpose |
|---|---|
| `pipeline.py` | loads the NLP models and extracts the signals |
| `ease_core.py` | keyword overlap, exact Shapley values, feedback rules (no heavy models) |
| `build_features.py` | runs the pipeline over the dataset and saves `data/features.csv` |
| `train.py` | cross-validation, ablation, final model, demo examples |
| `app.py` | Streamlit dashboard |

## Dataset

Mohler, M., Bunescu, R., & Mihalcea, R. (2011). Learning to Grade Short Answer Questions using
Semantic Similarity Measures and Dependency Graph Alignments. ACL. Loaded via Hugging Face:
`nkazi/MohlerASAG`.
